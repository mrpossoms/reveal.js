Policy Gradient Methods

REINFORCE

Environment — State Transitions

Policy — $\pi_\theta(.|s)$

Policy Gradient Methods

$$J(\theta) = \mathop{\mathbb{E}}_{\tau \sim \pi_{\theta}}[R(\tau)]$$ where $$R(\tau)=\sum_{t}\gamma^t r_t$$
  • Our objective is to maximize $J(\theta)$
  • We will do so by fiddling with $\theta$

Lets see how we get there..

Policy Gradient Methods

First, we reframe the expectation as an integral. By the definition of the expectation. $$ \mathop{\mathbb{E}}_{x \sim p(x)}[f(x)]=\int f(x)p(x) dx $$ We rewrite as... $$ \mathop{ \mathbb{E}}_{ \tau \sim \pi_{\theta}}[R(\tau)] = \int R(\tau) p_{ \theta }(\tau) d\tau $$ Where $p_{\theta}(\tau)$ is the probability of a trajectory $\tau$ under the policy $\pi_{\theta}$ and the environment dynamics.

Policy Gradient Methods

Next, we take the gradient w.r.t. $\theta$ $$ \nabla_{\theta}J(\theta) = \nabla_{\theta} \int R(\tau) p_{ \theta }(\tau) d\tau $$ Recognizing that $R(\tau)$ has no dependence on $\theta$... $$ \nabla_{\theta}J(\theta) = \int R(\tau) \nabla_{\theta} p_{ \theta }(\tau) d\tau $$ This is great, but no longer an expectation...

Policy Gradient Methods

A quick aside... Consider a function

$$ f(x) $$

Take the log of that function

$$ log(f(x)) $$

and differentiate it

$$ \frac{d}{dx} log(f(x)) = \frac{f'(x)}{f(x)} $$

Take note of this structure

Policy Gradient Methods

Right now we have... $$ \nabla_{\theta} p_{ \theta }(\tau) $$ We can be clever and add the following... $$ \textcolor{red}{p_{\theta}(\tau)}\frac{\nabla_{\theta}p_{ \theta }(\tau)}{\textcolor{red}{p_{\theta}(\tau)}} $$ $p_{\theta}(\tau)$ and $\frac{1}{p_{\theta}(\tau)}$ cancel out, so it changes nothing about our gradient.

Policy Gradient Methods

However you might have noticed that this $$ p_{\theta}(\tau)\textcolor{red}{\frac{\nabla_{\theta}p_{ \theta }(\tau)}{\textcolor{red}{p_{\theta}(\tau)}}} $$ Looks an awful lot like this $$ \frac{d}{dx} log(f(x)) = \textcolor{red}{\frac{f'(x)}{f(x)}} $$

Policy Gradient Methods

Which leads us to what's called the likelihood-ratio trick $$ \nabla_{\theta} p_{ \theta }(\tau)=p_{\theta}(\tau)\frac{\nabla_{\theta}p_{ \theta }(\tau)}{p_{\theta}(\tau)}=p_{\theta}(\tau)\nabla_{\theta}log(p_{ \theta }(\tau)) $$ This allows us to transform this term in our integral $$ \nabla_{\theta}J(\theta) = \int R(\tau) \textcolor{red}{\nabla_{\theta} p_{ \theta }(\tau)} d\tau $$ Into $$ \nabla_{\theta}J(\theta) = \int R(\tau) \textcolor{red}{p_{\theta}(\tau)\nabla_{\theta}log(p_{ \theta }(\tau))} d\tau $$

Policy Gradient Methods

Now we can take our integral $$ \nabla_{\theta}J(\theta) = \int \textcolor{orange}{R(\tau)} \textcolor{red}{p_{\theta}(\tau)}\textcolor{orange}{\nabla_{\theta}log(p_{ \theta }(\tau))} d\tau $$ And rearrange it into something recognizable as an expectation $$ \nabla_{\theta}J(\theta) = \int \textcolor{orange}{R(\tau)\nabla_{\theta}log(p_{ \theta }(\tau))} \textcolor{red}{p_{\theta}(\tau)}d\tau $$ Finally $$ \nabla_{\theta}J(\theta) = \mathop{\mathbb{E}}_{\tau \sim \pi_{\theta}}[\textcolor{orange}{R(\tau)\nabla_{\theta}log(p_{ \theta }(\tau))}] $$

Policy Gradient Methods

Unfortunately we still have $p_{\theta}(\tau)$ in our expectation. Which includes both our policy and the environment. $$ p_{\theta}(\tau)=\prod_{t}\pi_{\theta}(a_{t}|s_{t})P(s_{t+1}|s_{t},a_{t}) $$ We can't compute this directly, but luckily the term in question is actually $\nabla_{\theta}log(p_{\theta}(\tau))$ $$ \nabla_{\theta}log(p_{\theta}(\tau))=\sum_{t}\nabla_{\theta}log(\pi_{\theta}(a_{t}|s_{t}))+\sum_{t}\nabla_{\theta}log(P(s_{t+1}|s_{t},a_{t})) $$ The product turns into an sum.

Policy Gradient Methods

And the environment dynamics term $P$ has no dependence on $\theta$, its gradient is 0 $$ \nabla_{\theta}log(p_{\theta}(\tau))=\sum_{t}\nabla_{\theta}log(\pi_{\theta}(a_{t}|s_{t}))+\sout{\sum_{t}\nabla_{\theta}log(P(s_{t+1}|s_{t},a_{t}))} $$ Which leaves us with $$ \nabla_{\theta}log(p_{\theta}(\tau))=\sum_{t}\nabla_{\theta}log(\pi_{\theta}(a_{t}|s_{t})) $$

Policy Gradient Methods

A quick substitution of $$ \nabla_{\theta}log(p_{\theta}(\tau))=\textcolor{orange}{\sum_{t}\nabla_{\theta}log(\pi_{\theta}(a_{t}|s_{t}))} $$ Into $$ \nabla_{\theta}J(\theta) = \mathop{\mathbb{E}}_{\tau \sim \pi_{\theta}}[R(\tau)\textcolor{orange}{\nabla_{\theta}log(p_{ \theta }(\tau))}] $$ Gives us our final expectation $$ \nabla_{\theta}J(\theta) = \mathop{\mathbb{E}}_{\tau \sim \pi_{\theta}}[R(\tau)\sum_{t}\nabla_{\theta}log(\pi_{\theta}(a_{t}|s_{t}))] $$

Policy Gradient Methods

Now we have a computable gradient $$ \nabla_{\theta}J(\theta) = \mathop{\mathbb{E}}_{\tau \sim \pi_{\theta}}[R(\tau)\sum_{t}\nabla_{\theta}log(\pi_{\theta}(a_{t}|s_{t}))] $$ Finally we have what we need to adjust our policy $$ \theta' \leftarrow \theta + \alpha \nabla_{\theta}J(\theta) $$

Implementation

In practice this has a problem $$ \nabla_{\theta}J(\theta) = \mathop{\mathbb{E}}_{\tau \sim \pi_{\theta}}[\textcolor{red}{R(\tau)}\sum_{t}\nabla_{\theta}log(\pi_{\theta}(a_{t}|s_{t}))] $$
  • This weights all actions by the same return $R(\tau)$
    • Attributes past rewards to future actions
    • Ignores immediate reward of an action
  • Instead weigh $a_t$ by only its future rewards
    • This preserves causality
    • Reduces variance

Implementation

In light of this, we will replace $R(\tau)$ with the per-timestep return... $$ G_t = \sum_{k=t}^{T}\gamma^{k-t} r_{k} $$ And move $G_t$ inside the sum $$ \nabla_{\theta}J(\theta) = \mathop{\mathbb{E}}_{\tau \sim \pi_{\theta}}[\sum_{t}\textcolor{red}{G_t}\nabla_{\theta}log(\pi_{\theta}(a_{t}|s_{t}))] $$

Implementation

We still need a concrete way to compute our expecation. Enter Monte Carlo approximation $$\mathop{\mathbb{E}}[X] \approx \frac{1}{N}\sum_{n}^{N}x_n$$
  • Simple average
  • Approximates an expectation by drawing samples
  • We can do this through trials of environment interaction

Implementation

This allows for $$ \nabla_{\theta}J(\theta) = \mathop{\mathbb{E}}_{\tau \sim \pi_{\theta}}[\sum_{t=0}G_t\nabla_{\theta}log(\pi_{\theta}(a_{t}|s_{t}))] $$ to become $$ \nabla_{\theta}J(\theta) \approx \frac{1}{N}\sum_{n}^{N}\sum_{t}^{T^n}{G_t^n}\nabla_{\theta}log(\pi_{\theta}(a_{t}^n|s_{t}^n)) $$ Where $N$ is the number of trials (trajectories) sampled. Super script $n$ on quantities indicate which trajectory they belong to.

Implementation

Example implementation. 

                        function run_trials_and_optimize(env, theta, trials) {
                            // accumulator for policy gradient
                            let grad_theta = theta * 0;

                            for (let n = 0; n < trials; n++) {
                                let tau = [];

                                // set initial state of environment
                                let s_t = env.reset();
                                
                                // Sample the trajectory
                                for (let t = 0; t < 100; t++) {
                                    const a_t = sample(pi_theta(theta, s_t));
                                    const [s_t1, r_t] = env.step(a_t);

                                    if (r_t == null) { break; }

                                    tau.push([s_t, a_t, r_t])

                                    s_t = s_t1;
                                }

                                for (let t = 0; t < tau.length; t++) {
                                    const [s_t, a_t, r_t] = tau[t];

                                    // Compute per-timestep return
                                    const gamma = 0.99; 
                                    let G_t = 0;
                                    for (let k = t; k < tau.length; k++) {
                                        const [s_k, a_k, r_k] = tau[k];
                                        G_t += gamma**(k - t) * r_k;
                                    }

                                    // accumulate the gradient
                                    grad_theta += G_t * grad_theta_log_pi_theta(theta, a_t, s_t);
                                }
                            }

                            grad_theta /= trials; // Average by trial count

                            // take a step in the direction of the gradient
                            const alpha = 0.01;
                            return theta + alpha * grad_theta;
                        }
